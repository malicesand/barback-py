# Data Files Unique to User

## prefix.tsv
The photo prefixes unique to each photographer. A photographer can have more than one prefix. Ensure that while the prefixes are different, you maintain consistency with the name used. 

This document is compared to the photo metadata to determine who captured the photos in question

## Photographer Schedules
Photographer schedules uploaded from google calendar data. 

Naming convention: use the identifier from the prefix tsv. After photometada is read and compared against the prefix.tsv, the photog will be extracted and used to load each photographer's schedule
